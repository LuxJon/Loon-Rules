# 豆瓣去开屏广告

拦截开屏广告决策、竞价和预加载，提供可关闭的广告 SDK 兜底防护。

收录用户提供的 v4 防复发版，规则和默认参数保持原样；适用于 Loon 3.5.1（978）及以上版本，无需 JS。

## 安装

在 Loon 的插件页面添加远程订阅：

```text
https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/douban.plugin
```

启用插件及所需的复写／MitM，安装并信任 Loon 证书。替换原本地版本时，停用同功能旧插件，避免重复处理。

## 可选参数

- **第三方 SDK 兜底防护**：默认开启，补充拦截广告 SDK 请求及素材。部分域名由多个 App 共用，可能同时影响其他 App 的广告请求；如有非预期影响，可关闭此项。
- **开屏上报抑制**：默认开启，减少开屏广告相关上报。
