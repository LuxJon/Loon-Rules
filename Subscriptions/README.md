# 英文订阅地址

中文文件位于 [Plugins](../Plugins/)，本目录提供内容相同的固定英文订阅副本。

| 插件 | 订阅 |
| --- | --- |
| 节点检测整合 | [node-diagnostics.lpx](https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/node-diagnostics.lpx) |
| 哔哩哔哩竖屏优化 | [bilibili.lpx](https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/bilibili.lpx) |
| 豆瓣去开屏广告 | [douban.plugin](https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/douban.plugin) |
| 西窗烛会员解锁 | [xichuangzhu.plugin](https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/xichuangzhu.plugin) |
| QQ音乐启动动画屏蔽 | [qqmusic.plugin](https://raw.githubusercontent.com/LuxJon/Loon-Rules/main/Subscriptions/qqmusic.plugin) |

西窗烛原第三方脚本目前返回 404，收录状态见对应中文说明。

本目录由 <code>node scripts/sync-subscriptions.mjs</code> 生成，使用 <code>node scripts/sync-subscriptions.mjs --check</code> 检查与中文文件是否一致。
